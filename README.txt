# تطبيق مشتركي الكهرباء - Android

هذا مشروع Android مستقل يحتوي على برنامج إدارة مشتركي الكهرباء الحالي داخل WebView.
- يعمل بدون إنترنت.
- يخزن بيانات البرنامج داخل مساحة التطبيق.
- لا يعتمد على فتح ملف HTML من مجلد التنزيلات.
- اسم التطبيق: مشتركي الكهرباء

لإخراج APK:
1. افتح المشروع في Android Studio.
2. انتظر مزامنة Gradle.
3. اختر Build > Build APK(s).
4. ستجد APK في app/build/outputs/apk/debug/

البرنامج المضمّن هو index.html الموجود في app/src/main/assets.
